# Poetic Print Poster

Create or refine a photograph as a poetic 3:4 vintage editorial print poster, with a large serif word integrated into the scene, restrained English poetry, and fine CMYK halftone.

## What it does

- Preserves the source photo's subject, pose, viewpoint, and scene.
- Builds an airy poster layout with a short poem, oversized central word, and an original-photo inset.
- Uses image-specific colors and circular halftone texture.
- Supports narrow follow-up edits to palette, framing, typography, overlap, and texture.
- Distinguishes the actual edit target from any style-reference image.

## Install

Use this repository as the skill folder in an environment that supports Agent Skills. The folder must contain `SKILL.md` and the `agents/` and `assets/` directories.

For Codex, place the repository folder in your skills directory, typically `~/.codex/skills/poetic-print-poster`.

## Use

Invoke it with `@poetic-print-poster` and attach a photo. For an existing poster, identify the exact poster to edit and state which elements must stay unchanged.
